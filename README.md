# 城市公园场景休闲消费意愿调查

纯静态问卷。正式网站内容全部在 `site/`，不依赖 Python、数据库、API、npm 安装或外部前端 CDN。

## V2与原版本

原版完整代码保留在本地分支 `archive/static-v1`，对应已推送提交 `ce1a4d3`。可用 `git show archive/static-v1:site/assets/app.js` 查看，不需要覆盖当前文件。旧浏览器草稿 `park-survey-static-v1` 不会被V2修改；新版使用独立的 `park-survey-static-v2`，不自动迁移旧答卷。

## 填写与保存

直接进入基本信息，不再有说明或同意页面。包含第1—36题，基本信息只填一次，每个分配视频重复第13—36题。顶部居中显示完整问卷标题；显示进度，支持返回修改、当前浏览器自动保存恢复。选项横向换行，方案选项一行，频次三列两行，题目采用紧凑排版。风格说明常显且三类名称加粗。第11题“从未消费”清除并跳过第12题；方案“都不选”清除并跳过对应频次。更改编号会提示并清空已有场景答案。

完成后点击“下载Excel”，生成真正的 `.xlsx`，可用Excel/WPS打开编辑保存；网页返回修改后需重新下载。工作簿：

- **问卷数据**：仅标题行和一条受试者数据行。列名是题目名称；重复场景题额外带视频编码，避免混淆。第12题各选项拆为独立列，其他填写内容单独一列。
- **第12题多选**：按选项拆行，13个选项分别一行；保留受试者编号及其他文本。

单选与频次按原始选项顺序用数字1、2、3……记录；方案A/B/C/都不选分别1/2/3/4。第12题选中项填该项原序号1—13，未选为空。跳题、未作答均为空；受试者编号和“其他”自由文本保留文字。不会把未选填成0，不添加日期、状态、风格或价格等非题目列。所有文本使用Excel文本单元格保存，不当作公式执行。

答案只存于浏览器和下载文件，不上传、不集中收集。清除浏览器数据、无痕窗口关闭、换设备或换域名会影响恢复。下载文件不能导回网页。浏览器存储失败会提示，Excel下载发起后需确认文件已保存。

## 视频与编号

`site/assets/questions.js` 的 `videos` 对应视频地址；目前仅 C1、C2，二者使用用户提供的相同网址。支持 `C1`、`C2`、`C12`、`C21`。编号去空格转大写，验证字母A—M、数字1—9、重复数字及视频配置。可继续补齐117个视频。

视频高度为V1约两倍，顶部保持可见。iframe已允许autoplay，并给供应商地址附带autoplay=1、muted=1请求静音自动播放；跨域供应商是否支持参数、浏览器是否放行无法由本页强制保证。无官方播放器SDK，不通过操作跨域DOM或伪造观看事件来实现播放，不验证观看时长。已移除观看确认及说明文字。如需保证自动播放，需要供应商正式自动播放接口或获得授权的原视频地址。

## GitHub Pages自动部署

`.github/workflows/pages.yml` 已配置 `main` push 和手动 `workflow_dispatch`：检查JS与配置测试，上传 `site/`，通过官方 Pages Actions 部署。

首次使用：

1. 将当前代码提交并推送到 GitHub 仓库 `main`。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，并确认仓库允许 Actions（私有仓库的Pages可用性取决于GitHub套餐/组织策略）。
3. 到 **Actions → Deploy questionnaire to GitHub Pages** 查看结果；首次启用后如无运行，可点击 **Run workflow**。
4. 使用部署任务输出的 `page_url` 或 Pages 设置页提供的真实访问地址。后续 `main` 更新自动部署。

所有资源使用相对路径，适配 `/Questionaire/` 等项目路径。无需登录ChatGPT即可访问公开的Pages站点；不启用访问受限的企业Pages模式。工作区文件和工作流已配置，不等于已推送或在GitHub成功部署；V1已经推送并部署；V2此次仅修改本地代码，尚未推送或发布。

**GitHub Pages和第三方视频在中国大陆的可达性、速度无法保证。** 如需稳定国内访问，可把相同 `site/` 上传到国内静态托管/对象存储网站服务并配置HTTPS与域名；是否需要备案按接入商要求办理。静态版不需要后端，但无论托管在哪里都不会自动集中保存答卷。

## 开发检查

配置与Excel写入器测试只需 Node.js：

```sh
node tests/static.test.cjs
```

可选本地预览使用 Node 的开发静态服务器（不是运行/部署依赖）：

```sh
node tests/serve.cjs
```

默认本机8000端口，`PORT` 可覆盖。正式Pages部署无需运行这个命令。

浏览器回归测试为开发工具，使用本环境已安装的 Python Playwright 和 Chromium（不是应用或部署依赖）：

```sh
python tests/browser_smoke.py
```
