# 城市公园场景休闲消费意愿调查

纯静态问卷。正式网站内容全部在 `site/`，不依赖 Python、数据库、API、npm 安装或外部前端 CDN。

## 填写与保存

包含提供的第1—36题。基本信息只填一次，每个分配视频重复第13—36题。显示跳题后的适用题目进度，可返回修改，当前浏览器自动保存并恢复。第11题“从未消费”清除并跳过第12题；方案“都不选”清除并跳过对应频次。更改编号会提示并清空已有场景答案。

完成后点击“下载Excel答卷”，生成真正的 `.xlsx`，可用 Excel/WPS 打开并继续编辑保存；返回修改网站答案后需重新下载。工作簿包含：

- 基本信息：答卷ID、问卷版本、时间及第1—12题。
- 场景作答：每个视频每个业态一行，含选择、风格、价格、频次、跳题状态、视频顺序及版本。
- 方案配置：全部36个方案的风格、价格及方案组，可还原展示内容。

**答案仅存于受访者浏览器和下载文件，不上传、不集中收集。** 研究者需要通过约定渠道收回Excel。清理浏览器数据、无痕窗口关闭、换设备或换域名可能丢失本机恢复记录；下载文件不能导回网页。浏览器存储不可用时页面会提示；本机存储不应视为长期备份。Excel下载按钮表示发起下载，仍需参与者确认文件已保存。

## 视频与编号

`site/assets/questions.js` 的 `videos` 对应视频地址；目前仅 C1、C2，二者使用用户提供的相同网址。支持 `C1`、`C2`、`C12`、`C21`。编号去空格转大写，验证字母A—M、数字1—9、重复数字及视频配置。可继续补齐117个视频。

视频 iframe 支持由供应商提供的全景交互；重试不清除问卷答案，但会重置观看自报确认。供应商禁止嵌入时可“单独打开视频”后返回问卷。没有接入播放器SDK，不验证真实观看时长或视频完成量，观看确认只是受访者自报。

## GitHub Pages自动部署

`.github/workflows/pages.yml` 已配置 `main` push 和手动 `workflow_dispatch`：检查JS与配置测试，上传 `site/`，通过官方 Pages Actions 部署。

首次使用：

1. 将当前代码提交并推送到 GitHub 仓库 `main`。
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**，并确认仓库允许 Actions（私有仓库的Pages可用性取决于GitHub套餐/组织策略）。
3. 到 **Actions → Deploy questionnaire to GitHub Pages** 查看结果；首次启用后如无运行，可点击 **Run workflow**。
4. 使用部署任务输出的 `page_url` 或 Pages 设置页提供的真实访问地址。后续 `main` 更新自动部署。

所有资源使用相对路径，适配 `/Questionaire/` 等项目路径。无需登录ChatGPT即可访问公开的Pages站点；不启用访问受限的企业Pages模式。工作区文件和工作流已配置，不等于已推送或在GitHub成功部署；本次没有代为提交、推送或发布。

**GitHub Pages和第三方视频在中国大陆的可达性、速度无法保证。** 如需稳定国内访问，可把相同 `site/` 上传到国内静态托管/对象存储网站服务并配置HTTPS与域名；是否需要备案按接入商要求办理。静态版不需要后端，但无论托管在哪里都不会自动集中保存答卷。

## 开发检查

配置与Excel写入器测试只需 Node.js：

```sh
node tests/static.test.cjs
```

可选本地预览使用 Node 的开发静态服务器（不是运行/部署依赖）：

```sh
node tests/serve.cjs
```

默认本机8000端口，`PORT` 可覆盖。正式Pages部署无需运行这个命令。

浏览器回归测试为开发工具，使用本环境已安装的 Python Playwright 和 Chromium（不是应用或部署依赖）：

```sh
python tests/browser_smoke.py
```

覆盖项目子路径、手机/桌面、36题、跳题、场景隔离、返回修改、刷新恢复、XLSX下载及读取校验、无后端API请求。测试替换第三方视频，不代表真实视频或国内网络已验证。独立 `openpyxl` 读取器存在时额外校验工作簿。受管浏览器禁止 `file://`，该路径未测试。

修改问卷配置时更新 `version`；历史浏览器草稿版本不匹配时会提示。版本升级前应提醒参与者下载原答卷。研究过程中应冻结题目与方案版本。
